# 技术底座（固定不变，对用户不可见）

这部分是每次建站都相同的技术规格。Claude 直接执行，永远不需要问用户任何技术问题。

## 交付形态判断

按运行环境选择，不问用户：

1. **在 Claude Code / 有文件系统的环境**：React + Vite 项目，标准目录结构，附一条启动命令并用人话告诉用户"复制这行、粘贴、回车，浏览器就会打开你的网页"
2. **在 claude.ai 聊天界面**：单文件交付——优先 .jsx（React artifact）或自包含 .html（样式脚本内联），保证用户点开即看
3. 用户明确说要部署上线：产出静态构建产物，并推荐最简部署路径（如拖拽上传类的静态托管），给一步一步的人话操作指引

## 布局规格

- 桌面版心：内容最大宽度 1200-1700px（按风格卡片密度定：杂志/苹果风可宽，静默风可窄），水平居中，两侧安全边距 ≥ 24px
- 必须适配手机：单列堆叠、触控目标 ≥ 44px、字号不缩小到 14px 以下、图片自适应
- 间距系统：全站使用固定档位（4 / 8 / 16 / 24 / 40 / 64 / 96 / 160px），禁止随手写数值
- 字号系统：全站不超过 5 个字号档位

## 质量底线（不作为卖点提及，默默做到）

- 语义化标签（header/main/section/footer），图片有 alt
- 键盘可聚焦元素有可见 focus 样式
- 尊重 prefers-reduced-motion：用户系统开了减少动效，则关闭所有动画
- 颜色对比度：正文文字与背景对比 ≥ 4.5:1
- 图片：占位图用 CSS 渐变/色块生成，不引用外部图床；用户提供图片后做 object-fit 裁切保护
- 性能：不引入用不到的库；动画只用 transform/opacity；首屏不放超大资源

## 字体策略

- 中文：系统字体栈优先（PingFang SC / Hiragino Sans GB / Microsoft YaHei / 思源黑体），需要衬线时用 Noto Serif SC
- 英文展示字体：可用 Google Fonts（Playfair Display、Inter、JetBrains Mono 等），但整站 webfont ≤ 2 个
- 商用授权敏感：默认只用开源/系统字体，不用未授权商用字体

## 代码组织

- 单文件交付时：CSS 变量集中定义在顶部（把风格卡片的设计令牌直接变成 --变量），方便后续换肤
- React 项目时：设计令牌单独一个 tokens 文件；每个 section 一个组件；组件不超过 200 行
- 所有占位内容集中在一个数据对象/文件里，并加注释"// 等用户素材替换"，方便用户后续只改内容不碰代码

## 交付话术模板

交付时对用户说清三件事（全部人话）：
1. 这个页面有几屏、每屏是干嘛的
2. 哪些地方是占位内容，等他提供什么素材（列清单：几张什么样的图、几段什么内容的文字）
3. 下一步怎么反馈："直接说感受就行，哪里看着不舒服就告诉我"
