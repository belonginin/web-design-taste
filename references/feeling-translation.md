# 感受词 → 设计修改动作 翻译表

用户用感受性语言反馈时，按此表翻译成具体修改。每次修改后用人话告诉用户改了什么。
同一个感受词可能对应多个动作——先做最可能的 1-2 个，效果不对再换。

## 空间与密度

| 用户说 | 实际问题 | 修改动作 |
|---|---|---|
| "看着挤" / "喘不过气" | 留白不足 | section 间距 ×1.5；删掉一个次要元素；正文列宽收窄 |
| "太空了" / "冷清" | 内容密度或视觉锚点不足 | 增加一个视觉主体（大图/大字）；缩短 section 高度，而不是塞更多小元素 |
| "乱" / "不知道看哪" | 层级不清 | 每屏只留一个视觉焦点；统一对齐方式；砍掉一半的强调（粗体/颜色/大小） |
| "太单调" / "没重点" | 缺少对比 | 加大标题与正文的字号差（至少 3 倍）；给唯一的关键元素加签名处理 |

## 颜色

| 用户说 | 实际问题 | 修改动作 |
|---|---|---|
| "颜色脏" / "土" | 饱和度或色相混乱 | 降低饱和度；把所有彩色收敛到同一色相家族；检查是否有默认纯色（#FF0000 类）混入 |
| "太花" | 颜色数量过多 | 全页收敛到 1 个主色 + 中性色；彩色只留给最重要的一处 |
| "太素" / "没生气" | 缺少能量色 | 加一个点缀色，但只用在 1-2 处；或提高现有主色饱和度一档 |
| "太刺眼" | 对比过强或大面积高饱和 | 高饱和色从大面积背景改为小面积点缀；纯白底改暖白/冷白 |
| "显得廉价" | 常见于高饱和+渐变+阴影堆叠 | 减色、去渐变、阴影改为更淡更大范围（y 偏移大、透明度低） |

## 气质类（最常见也最模糊）

| 用户说 | 通常意味着 | 修改动作 |
|---|---|---|
| "不够高级" | 元素太多、颜色太多、字太大太粗 | 减色至 1+中性；留白 ×1.5；正文字号减 1-2px；去掉所有非必要图标和装饰 |
| "太像模板" / "AI 味" | 安全的居中对称+常见配色 | 换成不对称排版；把签名元素做得更极端一点；替换掉最常见的那个设计决定 |
| "不够专业" | 细节不齐 | 统一所有圆角/间距/字号为固定档位；对齐检查；文案改具体（数字、名词） |
| "太严肃" / "太冷" | 全是直角、冷色、粗体 | 圆角 +8px；色温调暖；加一处人味元素（照片/手写/口语化文案） |
| "太幼稚" / "太可爱" | 圆角过大、颜色过亮、字体过圆 | 圆角减半；饱和度降档；换利落字体 |
| "没有记忆点" | 签名元素不够突出 | 回到风格卡片的签名元素，把它做大做极端；其余全部再收敛一档 |

## 文字与内容

| 用户说 | 实际问题 | 修改动作 |
|---|---|---|
| "字太小/看不清" | 可读性 | 正文 ≥16px；检查文字与背景对比度；灰色文字加深 |
| "啰嗦" | 文案密度 | 每段砍半；把段落改成"一句主张+一行说明"结构 |
| "看不懂在卖什么" | 信息结构问题不是视觉问题 | 重写首屏：一句话说清"给谁+解决什么+凭什么信你" |

## 动效

| 用户说 | 实际问题 | 修改动作 |
|---|---|---|
| "太晃" / "头晕" | 动效过多过快 | 只保留入场淡入；删除所有循环动画 |
| "太死板" | 完全静态 | 加滚动淡入 + hover 反馈，仅此两种 |

## 兜底规则

- 用户说"就是感觉不对"但说不出哪里：不要瞎猜。截取当前页面的 2-3 个可疑点，做成选择题："你觉得更接近哪个问题：A 颜色不舒服 / B 排版没重点 / C 整体气质不对？"
- 用户连续两轮不满意同一处：停止微调，回到风格卡片层面问"要不要换一张卡片试试"
- 任何修改保持"一次只动一类东西"，让用户能看出因果
